# Offline panorama

Created with the built-in imagegen tool as one cartoon panorama; reduced to a single 180x120 image at `src/soomfon_control/assets/offline.png`. At shutdown Python cuts it into six equal 60x60 tiles, in a 3-column, 2-row layout. Only the tiny runtime sheet is kept in the project.

Prompt: One cohesive cartoon shutdown poster spanning six tiny square LCD keys, three columns by two rows. Deep navy background, bold cream/orange/red cartoon artwork. Top: unplugged cable at left, exhausted stream-controller mascot with X eyes in the middle, raised stop hand at right. Bottom: large tile-safe words “STOP”, “I'M”, “OFFLINE”. Friendly comic message that the controller is stopped and pressing buttons does nothing. Simple artwork readable at 180x120 total pixels, no grid lines or extra text.
