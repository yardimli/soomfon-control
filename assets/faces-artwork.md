# Faces screensaver artwork

Generated using the built-in imagegen tool: a single 8-by-8 photorealistic sprite sheet of fictional adult human faces with varied expressions. Source: `faces-sheet.png`. Runtime images: `faces/face-01.png` through `faces/face-64.png`, in row-major order, each 60 by 60 pixels. Cropping is reproducible with `tools/crop_faces.py`.

## Generation prompt

Create a production sprite sheet containing exactly 64 photorealistic HUMAN face portraits arranged in an exact uniform 8 columns by 8 rows grid. Square image, ideally 2048x2048. Every cell is exactly one eighth of total width and height. No gutters, margins, spacing, outlines, labels, text, watermarks or decorative borders. All 64 cells must be fully filled edge-to-edge. Each cell contains exactly one different realistic adult human face in a very tight frontal portrait, forehead to chin, face filling 90% of the cell, eyes and mouth fully visible, no hands or props. Diverse adults of different genders, skin tones, ages, hairstyles, facial hair. Natural skin texture and photographic studio lighting on a simple charcoal background, not cartoons, not emoji, not 3D renders. Each face has a clearly different expressive look, exaggerated enough to read on a tiny 60x60 display: joyful smiling, toothy laughing, belly laughing, winking, silly tongue out, cross-eyed, astonished, curious, confused, skeptical, suspicious, thoughtful, sleepy, yawning, tired, serene, sad, crying, teary, pouting, annoyed, angry, furious, disgusted, frightened, shocked, worried, nervous, embarrassed, blushing, shy, loving, puckering kiss, proud, smug, mischievous, sneaky, excited, dazed, dizzy, queasy, scrunched sneezing, cold grimace, overheated, relieved, bored, unimpressed, determined, concentrating, guilty, hopeful, gleeful, giggling, whistling, awkward grin, cheeky squint, contented, startled, surprised delight, deeply amused, doubtful, wistful, goofy, wide-eyed wonder. CRITICAL: precisely EIGHT columns and EIGHT rows, consistent aligned equal cell boundaries so a program can crop at exact eighths. No faces crossing between cells.
